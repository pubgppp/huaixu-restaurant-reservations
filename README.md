# 槐序小馆 · 在线预约演示

一个虚构餐厅的预约小项目，使用原生 HTML、CSS、JavaScript 和 Node.js 标准库，不需要安装第三方依赖。支持座位与每日限量菜品预订、预约查询与取消、店员查看与到店登记。

## 运行

需要 Node.js 20 或更新版本。在项目目录执行：

```bash
npm start
```

打开 <http://127.0.0.1:3000>。运行测试：`npm test`。

### 店员工作台

启动前设置至少 16 个字符的店员密钥，然后打开 <http://127.0.0.1:3000/staff>：

```powershell
$env:STAFF_KEY = 'replace-with-a-long-random-key'
npm start
```

店员可按日期查看预约、人数、羊排预留与备注，并将今天的有效预约标记为“已到店”。不设置 `STAFF_KEY` 时，后台接口不可用。密钥输入后只保留在当前页面内存中，不写入浏览器存储或 Git。

## 预约规则

- 可预约当天至未来 30 天、午市和晚市列出的时段。
- 每次预约 1–8 人，每个时段最多接待 20 人。
- 手抓羊排每天总共 10 份，每单最多预留 4 份，且不超过用餐人数。
- 提交时服务端再次检查座位与菜品余量，确认后写入 `data/reservations.json`。
- 预约成功会显示预约编号。凭预约编号和预留的手机号可查看预约，并在到店时间前取消。
- 取消后座位和手抓羊排余量会立即恢复。已标记到店的预约不能由顾客在线取消。演示项目没有支付功能。

## 数据说明

预约信息保存在运行本服务的电脑上，包含姓名和电话；整个 `data/` 目录已加入 `.gitignore`。预约查询与取消需要编号和预留手机号，接口按来源 IP 限制请求频率。请勿把它直接当作正式营业系统：公开上线前需要完善身份验证、分布式限流、隐私保护、备份恢复演练、跨进程并发控制和通知流程。部署和接口说明见 [运行与部署](docs/OPERATIONS.md)。

运行 `npm run backup` 可将当前预约数据复制到 `data/backups/`。备份含顾客联系方式，需妥善保管；可用 `BACKUP_DIR` 指定备份位置。恢复时先停止服务，再将选定备份复制回 `DATA_FILE` 指向的文件。

默认仅监听本机 `127.0.0.1:3000`。可通过 `PORT`、`HOST` 和 `DATA_FILE` 环境变量调整。
预约日期按 `RESTAURANT_TIME_ZONE` 计算，默认 `Australia/Sydney`；部署到其他地区时请设为餐厅所在地的 IANA 时区。
