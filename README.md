# 槐序小馆 · 在线预约演示

一个虚构餐厅的预约小项目，使用原生 HTML、CSS、JavaScript 和 Node.js 标准库，不需要安装第三方依赖。

## 运行

需要 Node.js 20 或更新版本。在项目目录执行：

```bash
npm start
```

打开 <http://127.0.0.1:3000>。运行测试：`npm test`。

## 预约规则

- 可预约当天至未来 30 天、午市和晚市列出的时段。
- 每次预约 1–8 人，每个时段最多接待 20 人。
- 手抓羊排每天总共 10 份，每单最多预留 4 份，且不超过用餐人数。
- 提交时服务端再次检查座位与菜品余量，确认后写入 `data/reservations.json`。
- 预约成功会显示预约编号。演示项目没有支付、取消或后台管理功能。

## 数据说明

预约信息保存在运行本服务的电脑上，包含姓名和电话；`data/reservations.json` 已加入 `.gitignore`。请勿把它直接当作正式营业系统：公开上线前需要完善登录权限、隐私保护、备份、跨进程并发控制和通知流程。

默认仅监听本机 `127.0.0.1:3000`。可通过 `PORT`、`HOST` 和 `DATA_FILE` 环境变量调整。

## Git 进度

计划分 20 次提交逐步完善；首日完成 4 次。后续可继续增加取消预约、店员管理、邮件提醒和部署配置等功能。
